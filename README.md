# Hotel Harmony – Hotel Booking Analysis

## Project Overview
This project focuses on performing Exploratory Data Analysis (EDA) on hotel booking data using Python. The objective is to understand booking trends, customer behavior, cancellation patterns, seasonal demand and hotel performance.

## Project Objectives
- Analyze hotel booking data.
- Understand booking trends and customer behavior.
- Compare City Hotel and Resort Hotel performance.
- Analyze booking cancellations.
- Explore seasonal booking patterns.
- Investigate customer distribution and booking lead times.
- Identify patterns through data visualization.

## Dataset
- **File:** `hotel_bookings.csv`
- **Source:** Hotel Booking Demand dataset.
